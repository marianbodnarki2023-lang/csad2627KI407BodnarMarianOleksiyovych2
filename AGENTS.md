# Repository Guidance

This repository contains VS Code GitHub Copilot customizations for an educational Python build-engineering project: a cross-platform Hello World app using `venv`, pytest, launch scripts, and GitHub Actions.

- Use [the build-engineer custom agent](.github/agents/build-engineer.agent.md) for project scaffolding, build/test setup, CI, and the repository commands it documents.
- Follow only the workflow explicitly requested. Read a referenced prompt or skill before relying on it; if it is missing, report that instead of inventing its contents.
- Write agent instructions and project documentation in Ukrainian. Keep file names, command names, and code identifiers in English.
